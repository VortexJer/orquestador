El ritual completo

Baja para abrir la merienda para dos

Tetera de porcelana

Una infusión de verdad necesita reposo — por eso sale a la mesa entera.

Dos tazas, dos platillos

La merienda se pide para compartir. Nunca para uno.

Azucarero y bandeja

Azúcar de caña, miel o nada: como la quieras.

Cada pieza en su sitio, cada tarde
